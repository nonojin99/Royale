# 종합 검토 — 게임이 성립하는가

> **후속 조치 완료**: 아래 P0 세 건은 검토 직후 수정되었다. 전후 비교는
> 문서 끝의 [수정 결과](#수정-결과-p0-세-건-처리-후-재실측)에 있다.

> 기준 커밋: 소총병 적용(94bd738) 시점. 밸런스 수치는 **헤드리스 자동 대전으로
> 실측**한 값이다 (시뮬이 순수 함수라 렌더링 없이 대량 실행이 가능하다).
>
> 탐침의 한계: 봇이 테크를 올리지 않으므로 아래 승률은 **시작 해금 유닛
> 기준의 오프닝 밸런스**다. 다만 결정적 경기가 41~88초에 끝나므로 어차피
> 테크가 개입할 시간이 없다 — 그게 바로 문제다.

## 요약

| 영역 | 상태 | 한 줄 진단 |
|---|---|---|
| 밸런스 | 🔴 **게임 불성립** | 경기가 "60초 러시"와 "300초 무승부" 두 극단뿐. 중간이 없다 |
| 조작감 | 🟡 골격은 좋음 | 유닛 정보가 게임 안 어디에도 없다. 연속 생산이 불편하다 |
| 그래픽 | 🟡 파이프라인 완성 | 유닛이 이동 방향과 무관하게 늘 아래를 본다. 기지·지형이 도형 |
| 사운드 | ⚫ 전무 | 계획(M9)만 있음 |
| 창의성 | 🟢 차별점 뚜렷 | 기지=생산반경, 일꾼 정원 경제. 다만 종족 차이가 유닛뿐 |

**결론: 다음 작업은 아트가 아니라 밸런스다.** 22종 아트를 다 입혀도 경기가
저 두 극단이면 재미를 판단할 수 없다. 아래 P0 세 건이 그 원인이고, 셋 다
구조적이라 수치 미세조정으로는 안 잡힌다.

## 1. 밸런스 — 실측 데이터

### 매치업 표 (시드 10개, 선/후공 교대, 시작 유닛 기준)

| 매치업 | 승수 | 무승부 | 평균 경기 | 종료 사유 |
|---|---|---|---|---|
| steel 미러 | 10 : 0* | 0 | **41초** | 본진파괴 ×10 |
| steel vs swarmhive | **0 : 10** | 0 | 52초 | 본진파괴 ×10 |
| steel vs covenant | **0 : 10** | 0 | 88초 | 본진파괴 ×10 |
| swarmhive 미러 | 2 : 0 | **8** | 266초 | 연장판정 ×8 |
| swarmhive vs covenant | 0 : 2 | **8** | 271초 | 연장판정 ×8 |
| covenant 미러 | 0 : 0 | **10** | 300초 | 연장판정 ×10 |

\* 미러전 10:0은 선공 자리(팀0)가 아니라 시드 우연 — 문제는 승패가 아니라 **41초**라는 시간이다.

무방비 본진 격파 시간(한쪽만 공격): steel 40초 · swarmhive 41초 · covenant 61초.

### P0-1 · 경기가 두 극단으로 갈린다

- **러시 극단**: 건물을 빨리 부수는 유닛(정찰차·물어뜯는것 물량)이 있는 매치업은
  41~88초에 본진이 터진다. 240초 기준으로 설계한 경제(매장량 100 = 포화 110초,
  일꾼 증원, 테크트리)가 **아예 개입하지 못한다.**
- **스톨 극단**: 그 유닛이 없는 매치업은 본진(HP 4000 + 자체 포격 70dps,
  사거리 6.5타일)을 서로 못 뚫고 300초를 다 쓴다.

원인은 대칭적이다: **시작 유닛의 대건물 화력이 극과 극**이다. 정찰차(2코스트,
속도 95, 건물 전용 130dmg)는 방어를 무시하고 본진에 직행하는데, 광전사(근접
120dmg)는 본진 포격을 맞으며 한참을 서 있어야 한다.

**제안 방향** — "방어는 초반에 강하고, 스톨은 테크가 깬다":
1. 시작 유닛의 대건물 효율 하향 (정찰차 건물 데미지 또는 속도 너프가 핵심)
2. 스톨 브레이커를 **2단계 테크에** 배치 — 공성전차·거대포식자·융합체가
   "본진을 깨는 유일한 효율적 수단"이 되게 대건물 보너스 부여
3. 목표 곡선: 러시 격파 최소 ~90초(방어 성립), 테크 완성 후 ~30초 내 종결 가능

### P0-2 · 승패 판정이 퇴화한다

연장 판정의 채굴량 비교가 장기전에서 무의미하다. 확장 없는 장기전은 양쪽 모두
본진 매장량 100을 **정확히 다 캐서** mined 100:100 → 기계적 무승부.
covenant 미러 10판 전부가 이렇게 끝났다.

**제안**: 판정 순서를 `기지 수 → 남은 기지 총 HP → 채굴량 → 무승부`로.
남은 HP는 "누가 더 때렸는가"를 그대로 반영하고 조작 불가능하다.
(시뮬 변경이므로 REPLAY_VERSION 올려야 함)

### P0-3 · 확장이 일어나지 않는다

병력 우선으로 플레이하면 미네랄이 유닛에 계속 빠져나가 확장 비용(8+α)을 모을
틈이 없다 — 3분 넘는 경기에서도 확장 0회, 본진 고갈 후 수입 0으로 연장전 진입.
"확장 = 수입 + 전선"이라는 핵심 설계가 실전에서 발화하지 않는다.

**제안**: P0-1이 잡히면(경기가 길어지면) 상당 부분 자연 해소된다. 그래도
부족하면 첫 확장 할인 또는 고갈 경고 강화. **본진 매장량(100)이 경기 길이보다
빨리 마르는 지금 균형 자체는 좋은 압박이니 유지.**

### P1 · 유닛 상한 부재 (재확인)

스톨 경기에서 동시 75유닛 관측. O(n²) = 틱당 ~5,600쌍으로 아직 여유지만,
러시가 막히는 방향으로 조정하면 물량이 더 쌓인다. M7.6 상한 도입을 앞당길 것.

## 4. 사운드 (전무)

M9 계획 그대로. 최소 세트 5종이면 체감이 달라진다:
**배치 · 발사(종족별 1) · 유닛 사망 · 본진 피격 경보 · 연구 완료.**

외부 에셋 없이 Web Audio 절차 생성으로 시작하는 것을 권한다 — 에셋 파이프라인
없이 코드만으로 되고, 종족별 음색(기갑단 노이즈/타격, 군체 유기음, 신념단
정현파 화음)이라는 정체성 표현 여지도 있다.

## 5. 창의성 · 정체성

**이미 차별적인 것**: 기지 반경 = 생산 가능 구역(확장이 곧 전선), 일꾼 정원
경제, 유한 매장량, 종족 필드 물들임, 시드+커맨드 리플레이. "클래시 로얄 카피"
단계는 확실히 벗어났다.

**아이디어 (밸런스 안정 후)**:
- 종족 경제 비대칭 소폭 — 군체 확장 -2코스트 / 신념단 연구 20% 단축 /
  기갑단 기지 HP +25% 같은 한 줄짜리 차이
- 중앙 기지 자리 매장량 150 — 중앙 고지를 다툴 경제적 이유
- 리플레이 요약에 최다 활약 유닛 표기 — 공유 재미

## 수정 결과 (P0 세 건 처리 후 재실측)

같은 탐침(시드 10, 선/후공 교대)으로 재측정. 봇에는 저축 로직을 넣어
확장(8)·2단계 테크(12)에 실제로 도달하게 했다.

| 지표 | 수정 전 | 수정 후 |
|---|---|---|
| 무승부 | 26 / 60 | **0 / 60** |
| 평균 경기 시간 | 41초(러시) 또는 300초(스톨) | **91~110초, 전부 본진파괴 종결** |
| 무방비 격파 | 40 / 41 / 61초 | **79 / 85 / 96초** |
| steel 상대전적 | 0:20 | 3:7 (군체) · 6:4 (신념단) |
| 확장 발생 | 0회 | 8판에 24회, 매크로 8:0 병력 |

### 무엇을 바꿨나

1. **P0-2 판정** — `기지 수 → (연장) → 남은 기지 총 HP → 채굴량 → 무승부`.
   REPLAY_VERSION 2→3.
2. **P0-1 공성 배율(siege)** — UnitDef에 구조물 상대 백분율 배율 추가.
   시작 유닛 30~60(방어 성립), T1 러시 쌍(정찰차·굴착충) 120으로 나란히,
   2단계 공성(공성전차 220 · 거대포식자/융합체 200)이 스톨 브레이커.
   기갑단은 시작을 소총병+**화염병**으로 바꾸고 정찰차를 T1로 — "방어형"이
   정작 시작 방어가 없던 문제. 화염병 100뎀은 물어뜯는것(95hp) 한 방 기준점.
3. **P0-3 저축** — 봇이 확장·연구 목표액만큼 병력 지출을 참는다. 이게 없으면
   유닛 2~3코스트가 미네랄을 계속 빨아들여 8·12에 영원히 못 도달한다.
   클라이언트에 "곧 고갈"(25% 미만) 경고 추가.

### 남은 것 (M8로)

- steel vs 군체 3:7 — 무작위 생산 봇 기준이라 과대평가일 수 있다. 전략형
  봇(화염병 우선 등)으로 재면 다를 것. 45~55% 수렴은 M8 몫.
- 미러전에서 완전 대칭 플레이도 미시 타이브레이크로 갈린다(8판 2:6, 시드
  의존). 고정 편향이 아니라 수용 — 영구 교착을 깨주는 성질이기도 하다.
