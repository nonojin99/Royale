# 로그라이트 싱글 설계 — "침공" (라운드 22 방향 확정)

## 왜 스토리 캠페인이 아닌가

1인 개발의 산수: 캠페인 미션은 **저작 콘텐츠**(미션당 시나리오·스크립트·
밸런스 한 벌씩, 클리어하면 소진)이고, 로그라이트는 **조합 콘텐츠**(유물
20종 = 코드 20줄, 유물×종족×맵 조합이 리플레이성을 생성)다. Slay the
Spire 모델. 결정론 시뮬·봇·맵·하네스 전부 재사용. 스토리는 미션 브리핑
한 줄의 플레이버로 압축한다.

## 3단계 — 첫 단계는 주말 크기

### 1단계: 침공 (파도 방어 프로토타입) — ✅ 라운드 23 구현
- 스크립트 파도: N초마다 적 유닛 무리 배치, 파도마다 예산 +15%
- 실험장의 적군 배치 코드가 곧 스포너 — 봇·새 AI 불필요
- 기존 맵 1개, 기존 유닛 그대로, 점수 = 버틴 파도 수
- **관문 (Tyroller 3주 규칙)**: 여기서 재미없으면 로그라이트를 접는다

### 2단계: 드래프트 (로그라이트의 심장) — ✅ 라운드 25 구현
- 파도 사이 3택1 유물: "소총병 코스트 -1" "충전 2배 속도" "기지 체력
  +50%" "타 종족 유닛 영입" …
- 구현 = PlayerState 수정자 (유물 1종 = 코드 몇 줄, 결정론 유지)
- 카드 UI 문법 재사용

### 3단계: 런 체인 + 영웅
- 맵 3연전 (파도전 → 수비전 → 보스 둥지 격파)
- 라운드 11에서 격리한 영웅이 런 시작 픽으로 등판 — 대전 밸런스 불가침

## 침공 2.0 — 치열함의 설계 (라운드 24 협의체)

### 진단: 왜 안 치열한가 (오너 실측 — 전 확장 후 13파도 한가)

1. **경제가 무한** — 확장을 다 먹으면 수입 복리가 파도 성장을 앞지른다.
   파도 사이가 "위기 대비"가 아니라 "저축 시간"이 된다
2. **파도가 단조** — 예산만 커진다. 조성이 안 바뀌니 "다음엔 뭘 준비해야
   하지"라는 결정이 없다
3. **성장 축이 없다** — 런의 정체성이 없고, 기존 테크를 반복할 뿐

### 처방 5안 (협의체 순위)

**B. 경제 재설계 — "파도가 곧 자원" (1순위, 기존 맵에서 가능)**
채굴 수입 절반, 대신 파도 클리어 보상(파도 예산의 60~80%를 미네랄로).
버티기만 하면 가난해지고 빨리 소탕할수록 부유 — 치열함의 엔진.
확장은 수입이 아니라 전선(방어 거점)이 된다.

**C. 파도 테이블 + 예고 (1순위와 한 몸)**
예산 성장 위에 타입 스크립트: 5파도마다 특수 파도 — 공중 파도(대공 강제),
공성 파도(원거리 우선), 러시 파도(물량), 10파도마다 보스 1기+호위.
HUD에 **다음 파도 조성 예고** (Into the Breach 완전 정보) — 예고가 있어야
준비가 결정이 되고, 준비가 결정이어야 함락이 "내 탓"이 된다.

**A. 전용 맵 '포위' (2순위)**
중앙 본진, 8방향 개활 스폰. 확장 지점이 본진에서 바깥으로 뻗어 —
확장할수록 지킬 전선이 넓어지는 리스크 트레이드. 침공 전용, PvP 제외.

**D. 드래프트 (3순위 — 2단계 선행 도입)**
파도 클리어마다 3택1 유물. 성장 축의 본체.

**E. 시작 유닛 제한 (4순위)**
런 시작 시 종족 유닛 3종만, 나머지는 드래프트로 해금 — 매 런 다른 조합.

### 즉효 패치 (라운드 24에 이미 적용)
- 예산 성장 118→126%, 간격 22초→최소 10초
- 스폰 모서리 3방향 로테이션 (내 본진 코앞 제외)
- 침공자 기지 제거 + 무표적 아군 제자리 대기 (순례 버그 해소)

## 내부 시스템 특장점 로드맵 (라운드 27 협의체)

오너 진단: "틀만 있고 내부 시스템의 특장점이 없다. 동일 장르 게임은
건물·방벽 설계·스킬·특성·스탯 여러 축으로 개성을 뽑는다."

우리 구조에서 **가장 싸게 깊이를 만드는 축** 순서로 적는다. 각 축은 이미
있는 뼈대(결정론 시뮬·드래프트·게이지 스킬)에 얹히므로 새 엔진이 없다.

### 1축. 방벽 = 지형 — ✅ 라운드 29 구현 (침공 전용)
**방어 건물이 nav의 장애물이 되게 한다.** 지금 방벽은 유닛이 밀리는 덩어리일
뿐이지만, 길찾기 장애물이 되면 **플레이어가 미로를 설계**한다 — 파도를 긴
사선으로 유도하고, 그 사선에 포탑·화염병을 배치하는 것이 곧 전략이 된다.
이 한 줄 변경이 "터렛 놓기"를 "성 설계"로 바꾼다.
- 필수 안전장치: 본진→맵 밖 경로가 완전히 막히면 배치 거절(BFS 검사) —
  스타의 "완전 봉쇄 금지" 규칙과 같다. 막다른 길은 허용, 완전 폐쇄는 금지
- 후속: 벽 전용 저가 건물(체력만 있는 바리케이드) 추가

### 2축. 건물 계보 — ✅ 라운드 31 구현 (침공 전용)
현재 방어 건물은 종족당 1~2종. 침공에서는 **건물이 곧 빌드**가 되어야 한다:
- 감속 타워(진군 속도 -40%), 지원 타워(주변 아군 공격 +15%),
  수리 거점(주변 건물 체력 회복), 대공 전용 vs 지상 전용 분화
- 드래프트로만 해금 → 매 런 다른 성이 된다

### 3축. 유닛 특성 — ✅ 라운드 32 구현
드래프트 유물을 **유닛 지정형**으로 확장: "소총병: 사거리 +1", "광전사:
처치 시 체력 회복", "강철거인: 죽을 때 폭발". 같은 유닛이 런마다 다른
역할이 되고, 조합이 빌드의 정체성이 된다.

### 4축. 능동 스킬 확대 (게이지 틀 재사용)
라운드 21의 충전 스킬 틀에 얹는다: 은신(그림자), 디텍팅(정찰차),
시즈모드(공성전차), 지뢰(방벽), 속도증가(굴착충).

### 5축. 영웅 (라운드 11에서 격리한 것)
런 시작 픽 — 고유 능동기 1개 + 성장. 3단계 런 체인과 함께.

**권고 순서**: 1축(방벽 지형화) → 2축(건물 계보) → 3축(유닛 특성) →
4축 → 5축. 1축이 가장 싸고 가장 크게 바꾼다.


## 1축 실측 결과 (라운드 29)

- **길찾기 격자에 동적 장애물 레이어** 추가: 건물이 중심+직교 4칸(십자)을
  막는다. 근거는 물리 — 건물 반경 900 + 유닛 반경 400 = 1300이라 이웃
  칸까지 막아야 길찾기와 충돌이 어긋나지 않는다(어긋나면 라운드 19식 낌)
- **완전 봉쇄 금지**: 배치 전 BFS로 네 모서리·적 본진 → 내 본진 경로가
  남는지 검사. 남지 않으면 거절(클라가 같은 검사로 즉시 알린다).
  실측: 본진 포위 64회 시도 → 10회 거절, 경로는 언제나 잔존
- **유도 확인**: 북문에 방벽 2기 → 경로비용 170 → 210 (+24% 우회)
- **성능**: 건물 20개 연속 배치 중 최악 틱 0.2ms (예산 50ms)
- **대전 제외 결정**: 대전에 켜 보니 삼각이 무너졌다 (RUSH vs TECH
  58% → 38% — 방어 건물이 접근로를 닫는다). 침공 전용으로 좁히고 대전은
  방어 건물 재튜닝 라운드 이후로 미룬다. 기존 모드는 건드리지 않는다
- **방벽은 공짜 힘이 아니다**: 문 앞 방벽 8기를 짓는 스크립트가 물량만
  뽑는 스크립트보다 **못 버텼다**(9파도 vs 13파도) — 자원을 벽에 쓰면
  화력이 준다. 좋은 배치만이 이득이 되는 트레이드, 의도한 깊이다


## 2축 실측 결과 (라운드 31)

침공 전용 중립 지원 건물 3종. **스스로 쏘지 않고 주변을 바꾼다** — 공격
타워만 있으면 성 설계가 "포탑 몇 개"로 납작해진다.

| 건물 | 오라 | 실측 |
|---|---|---|
| 냉각탑 | 반경 4.5 · 적 이동 -40% | 진군 38% 감소 (킬존에 가둔다) |
| 지휘탑 | 반경 5.0 · 아군 유닛 공격 +15% | 10초 피해 +12% (절단 오차 포함) |
| 정비고 | 반경 4.0 · 아군 건물 초당 25 회복 | 방벽 10초에 250 회복 |

- 오라는 **겹치면 더해진다**(겹치는 자리를 만드는 것이 설계의 묘미).
  감속만 90%에서 자른다 — 완전 정지는 파도를 영구히 세워 게임을 멈춘다
- 지휘탑은 **유닛 공격만** 키운다. 건물까지 키우면 성이 성을 키워 무한이 된다
- 종족 트리에 없다 → 대전에 새지 않는다(테스트가 강제). 드래프트로만 해금


## 3축 실측 결과 (라운드 32)

유닛 지정형 특성 유물 6종. 같은 유닛이 런마다 다른 역할이 된다.

| 유물 | 효과 | 실측 |
|---|---|---|
| 정밀 조준 | 소총병 사거리 +1.5타일 | 5.8타일 표적: 390 → 1170 피해 |
| 광신 | 광전사 공격 +35% | 10초 피해 1200 → 1620 (+35%) |
| 불안정 노심 | 강철거인 사망 시 240·2.5타일 폭발 | 반경 안 240 / 밖 0 |
| 갑각 | 물어뜯는것 체력 +70% | (합산 방식 — 강철 심장과 곱 아님) |
| 포격 교본 | 공성전차 공격 +30% | |
| 전투 각성제 | 전군 이동 +18% | 3초 행군 2.99 → 3.55타일 (+19%) |

- **겨냥한 유닛이 미해금이면 드래프트에 나오지 않는다** — 죽은 카드가
  섞이면 3택1이 2택1로 줄어든다 (테스트가 강제)
- 잡은 버그: 시체를 걷어가는 길이 둘(reap·resolveDeaths)인데 한쪽만
  폭발을 처리해, 수명·주문으로 죽은 유닛은 조용히 안 터졌다 → 공용 함수로 통합
