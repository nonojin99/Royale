# 유닛 아트 생성 지시서

한 유닛씩 이 문서를 보고 생성 → 자르기 → 확인. **§1을 그대로 복사해 붙이고
§4에서 해당 유닛 줄만 바꿔 넣으면 된다.**

관련 문서: [ART_PIPELINE.md](./ART_PIPELINE.md) (규격 근거) ·
[public/art/README.md](../packages/client/public/art/README.md) (도구 사용법)

---

## 1. 생성 프롬프트 (공통 부분 — 그대로 복사)

```
2행 5열 스프라이트 시트를 만들어 줘.

[형식]
- 투명 배경 PNG. JPG 금지.
- 1행: 걷기 5프레임 (왼발 → 중간 → 오른발 → 중간 → 정지 순환)
- 2행: 공격 5프레임 (0번은 공격 전 중립 자세, 2~3번에 타격 순간)
- 두 행의 캐릭터를 **완전히 같은 크기, 같은 디자인**으로.
- 프레임 번호나 라벨 같은 글자를 이미지에 넣지 말 것.

[구도]
- 3/4 탑다운 (위에서 약 45도 내려다본 각도).
- 캐릭터는 화면 아래쪽(보는 사람 쪽)을 향해 서 있다.
- 광원은 왼쪽 위, 그림자는 오른쪽 아래.
- 각 프레임 안에서 가로 중앙, 발이 아래에서 약 12% 지점.
- 프레임끼리 겹치지 않게 좌우 여백을 넉넉히.

[화풍]
- 2D 픽셀아트 느낌의 게임 스프라이트. 진한 외곽선과 또렷한 명암.
- 실사풍·3D 렌더링 느낌 금지.
- 배경 요소(바닥, 그림자 원, 이펙트 잔상) 넣지 말 것. 캐릭터만.

[캐릭터]
<< §4에서 해당 유닛 줄을 여기에 붙여넣기 >>
```

### 왜 이 규격인가

| 규칙 | 어기면 |
|---|---|
| 투명 PNG | 체크무늬가 픽셀로 구워져 유닛마다 회색 사각형이 따라붙는다 |
| 한 장에 2행 | 따로 뽑으면 디자인이 어긋난다 — `gnawer`는 걷기가 거미, 공격이 전갈로 나왔다 |
| 두 행 같은 크기 | `devourer`가 공격에 들어가는 순간 크기가 튀었다 |
| 0번이 중립 자세 | 몸 크기 기준으로 쓴다. 여기에 이펙트가 있으면 몸이 작아진다 |
| 라벨 금지 | 이미지에 구워지면 잘라내야 하고, 안 자르면 유닛이 2.5배 작아진다 |
| 발이 12% 지점 | 발밑 팀 색 링과 어긋난다 |

## 2. 진행 현황

**12/24 유닛에 이미지가 일부 있고, 그중 3개는 재생성이 필요하다.**

### 재생성 필요 (3)

| 유닛 | 문제 |
|---|---|
| `gnawer` 물어뜯는것 | 걷기와 공격이 **다른 생물** (거미 vs 전갈) |
| `mystic` 술사 | 걷기와 공격의 갑옷 디자인이 다름 |
| `devourer` 거대포식자 | 같은 생물이나 **그려진 크기가 달라** 화면 크기가 튐 |

### 한쪽만 있음 — 나머지 행만 있으면 되지만, 2행으로 다시 뽑는 게 낫다 (9)

| 유닛 | 있는 것 | 없는 것 |
|---|---|---|
| `rifleman` 소총병 | 공격 | 걷기 |
| `siegetank` 공성전차 | 공격 | 걷기 |
| `wingswarm` 날개무리 | 공격 | 걷기 |
| `zealot` 광전사 | 공격 | 걷기 |
| `flamer` 화염병 | 걷기 | 공격 |
| `scoutcar` 정찰차 | 걷기 | 공격 |
| `spitter` 가시뱉는것 | 걷기 | 공격 |
| `lightpylon` 빛기둥 | 정지 1장 | (건물이라 이대로도 됨) |
| `spinetentacle` 가시촉수 | 정지 1장 | 공격 |

### 아직 없음 (12)

`bulwark` `ironwalker` `gunship` `carpetbomb` `tunneler` `burrower`
`sporetentacle` `strider` `shade` `fusionite` `skiff` `mindbreak`

## 3. 유닛 종류별 요령

| 종류 | 행 구성 | 비고 |
|---|---|---|
| **이동 유닛** | walk + attack | 기본 |
| **건물** (`bulwark` `spinetentacle` `sporetentacle` `lightpylon`) | idle + attack | 걷지 않는다. 1행은 정지 자세 5프레임(맥동·발광 정도) |
| **주문** (`carpetbomb` `mindbreak`) | — | 유닛이 아니라 화면 효과다. 지금은 생성하지 말 것 |
| **공중** (`gunship` `wingswarm` `skiff`) | walk + attack | 걷기 대신 **비행 순환**(날개짓/부유). 다리·바퀴 없이 |

## 4. 유닛별 캐릭터 설명

원문 그대로 §1의 `[캐릭터]` 자리에 붙여 넣는다. **크기 등급이 가장 중요하다** —
코드는 유닛별 배율을 주지 않고 이미지 안의 비율로만 덩치를 표현한다.

### 기갑단 (steel) — 인간 기계화 보병. 회청색 장갑 + 주황 표식

| id | 이름 | 코스트 | 등급 | 캐릭터 설명 (붙여넣기용) |
|---|---|---|---|---|
| `rifleman` | 소총병 | 3 | 중형 70% | 회청색 강화복을 입은 인간 보병. 각진 헬멧과 어깨 장갑, 양손으로 소총을 앞으로 겨눔. 주황색 발광 바이저. 어깨가 넓어 보이게 |
| `scoutcar` | 정찰차 | 2 | 중형 70% | 회청색 4륜 소형 장갑차. 낮고 납작한 차체, 앞쪽에 충각. 바퀴가 굵고 흙받이가 있음. 건물만 노리는 돌격 차량 |
| `flamer` | 화염병 | 3 | 중형 70% | 등에 연료탱크를 멘 회청색 보병. 짧고 굵은 화염방사기를 앞으로 듦. 공격 시 주황 화염이 앞으로 뿜어짐 |
| `bulwark` | 방벽 | 3 | 중형 70% | **건물.** 회청색 자동포탑. 콘크리트 기단 위에 회전 포탑, 쌍열 기관포. 주황 경고등 |
| `ironwalker` | 강철거인 | 4 | 대형 90% | 2족 보행 중장갑 로봇. 회청색, 양 어깨에 대형 포. 다리가 굵고 발이 넓적함. 조종석 창이 정면 |
| `siegetank` | 공성전차 | 5 | 대형 90% | 궤도식 자주포. 회청색 차체에 길고 굵은 주포가 앞을 향함. 낮고 넓적하며 육중함. 공격 시 포구 화염과 탄피 배출 |
| `gunship` | 전투비행선 | 4 | 대형 90% | **공중.** 회청색 무장 헬기형 비행선. 양옆에 로터 또는 추진기, 아래에 미사일 포드. 다리 없이 떠 있는 자세 |

### 군체 (swarmhive) — 유기체 무리. 갈색 키틴 + 보라색 속살

| id | 이름 | 코스트 | 등급 | 캐릭터 설명 (붙여넣기용) |
|---|---|---|---|---|
| `gnawer` | 물어뜯는것 | 2 | **소형 55%** | 갈색 키틴 껍질의 네발 벌레. 몸통이 작고 낮으며, 머리에 큰 낫 모양 앞발톱 한 쌍. 보라색 속살이 관절 사이로 보임. 빠르고 날렵한 인상 |
| `spitter` | 가시뱉는것 | 3 | 중형 70% | 상체를 세운 갈색 벌레. 목이 길고 입이 크게 벌어짐. 등에 가시 돌기. 공격 시 보라색 산성 가시를 뱉음 |
| `tunneler` | 굴착충 | 2 | 중형 70% | 땅을 파는 갈색 지렁이형. 앞쪽에 회전하는 원형 이빨 구조. 몸통이 마디로 나뉨. 건물만 노리는 자폭형 인상 |
| `spinetentacle` | 가시촉수 | 3 | 중형 70% | **건물.** 땅에서 솟은 갈색 촉수. 뿌리 부분은 살덩이 기단, 위로 갈수록 가늘어지며 끝이 뾰족한 창 모양. 지상만 공격 |
| `burrower` | 땅속의것 | 4 | 중형 70% | 몸의 절반이 땅에 묻힌 갈색 벌레. 지면 위로 등껍질과 머리만 드러남. 느리지만 단단해 보이게 |
| `sporetentacle` | 포자촉수 | 3 | 중형 70% | **건물.** 가시촉수와 같은 계열이나 끝이 벌어진 꽃봉오리 형태. 보라색 포자 주머니. 공중만 공격 |
| `wingswarm` | 날개무리 | 4 | 대형 90% | **공중.** 갈색 날개 달린 벌레 여러 마리가 뭉친 무리. 넓게 펼친 막 날개. 다리 없이 떠 있는 자세 |
| `devourer` | 거대포식자 | 5 | 대형 90% | 거대한 갈색 사족 괴수. 두꺼운 등껍질, 머리 양옆에 거대한 상아 같은 엄니 한 쌍. 보라색 속살. 화면을 압도하는 덩치 |

### 신념단 (covenant) — 금빛 갑주와 청록 에너지

| id | 이름 | 코스트 | 등급 | 캐릭터 설명 (붙여넣기용) |
|---|---|---|---|---|
| `zealot` | 광전사 | 3 | 중형 70% | 금빛 갑주를 입은 인간형 전사. 어깨와 투구에 장식. 양팔에서 청록색 에너지 검이 뻗어 나옴. 근접 돌격 자세 |
| `lightpylon` | 빛기둥 | 3 | 중형 70% | **건물.** 금빛 골조에 청록 수정이 박힌 탑. 위로 갈수록 좁아지는 첨탑. 수정이 발광 |
| `strider` | 사격보행기 | 4 | 중형 70% | 금빛 4족 보행 기계. 몸통은 둥근 캡슐형, 다리는 가늘고 관절이 많음. 정면에 청록 에너지 포 |
| `shade` | 그림자 | 4 | 중형 70% | 반투명한 어두운 인간형. 금빛 테두리만 또렷하고 몸통은 흐릿함. 긴 발톱. 은신한 암살자 인상 |
| `mystic` | 술사 | 4 | 중형 70% | 긴 금빛 예복을 입은 인간형. 다리가 안 보이고 옷자락이 바닥까지. 손 위에 청록 에너지 구체. 지팡이나 부유 장식 |
| `fusionite` | 융합체 | 5 | **대형 90%** | 금빛 갑주가 겹겹이 융합된 거대 인간형. 어깨가 매우 넓고 등에 에너지 코어. 청록 빛이 갑주 틈으로 새어 나옴 |
| `skiff` | 부유선 | 4 | 중형 70% | **공중.** 금빛 유선형 소형 비행선. 날개 없이 부유. 아래쪽에 청록 에너지 추진 광채 |

## 5. 받은 뒤 처리

```bash
cd packages/client

# 1) JPG로 왔거나 배경이 구워졌으면 (아니면 건너뜀)
node tools/dealpha.mjs ../../art-src/gnawer.png

# 2) 자르기 — 먼저 --dry 로 확인
node tools/slice-sheet.mjs ../../art-src/clean/gnawer.png \
     --unit gnawer --rows walk,attack --dry

# 3) 문제 없으면 --dry 빼고 실행
node tools/slice-sheet.mjs ../../art-src/clean/gnawer.png \
     --unit gnawer --rows walk,attack
```

등급은 `tools/tiers.json`이 갖고 있으므로 `--tier`를 줄 필요가 없다.
출력된 내용을 `public/art/manifest.json`에 붙여 넣으면 끝.

### 흔한 실패

| 증상 | 원인 | 대처 |
|---|---|---|
| `JPG다 — 알파 채널이 없다` | 확장자만 png | `dealpha.mjs` 먼저 |
| `투명한 픽셀이 거의 없다` | 배경이 구워짐 | `dealpha.mjs` 먼저 |
| 프레임이 5개가 아님 | 섬광이 프레임을 이어 붙임 | `--frames 5` 추가 |
| `얇은 띠가 있다` 경고 | 라벨이 구워짐 | `dealpha.mjs --cropbottom <알려주는 %>` |
| 행이 2개로 안 나뉨 | 행 간격이 좁음 | 자동으로 높이 2등분으로 넘어감. 결과 확인할 것 |

## 7. 우선순위

1. **재생성 3종** (`gnawer` `mystic` `devourer`) — 지금 화면에서 어긋나 보인다
2. **시작 해금 유닛** — 경기 시작하자마자 보인다
   `rifleman` `scoutcar` / `gnawer` `spitter` / `zealot` `lightpylon`
3. **1단계 테크** — 대부분의 경기에서 등장
   `flamer` `bulwark` `ironwalker` / `tunneler` `spinetentacle` `burrower` /
   `strider` `shade` `mystic`
4. **2단계 테크** — 후반에만
   `siegetank` `gunship` / `sporetentacle` `wingswarm` `devourer` /
   `fusionite` `skiff`
5. 주문 2종(`carpetbomb` `mindbreak`)과 건물 이펙트는 M7.5(이펙트)에서 따로
